# Solana Bounty & Portfolio dApp

🚀 **Live Demo:** [https://solana-bounty-dapp.vercel.app/](https://solana-bounty-dapp.vercel.app/)

A full-stack Solana decentralized application built for managing bounties, showcasing Web3 projects, and facilitating peer-to-peer micro-task escrow on the Solana blockchain.

---

## ⚡ Features

- **Wallet Integration:** Seamless connection via Solana Wallet Adapter (Phantom, Solflare, Backpack).
- **On-Chain Escrow & Micro-Payments:** Secure allocation of SOL tokens for completed bounty milestones.
- **Responsive UI/UX:** Modern, high-performance interface built with Next.js App Router and Tailwind CSS.
- **Production Ready:** Deployed globally via Vercel edge networks with high reliability.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (React 19 / App Router)
- **Blockchain:** [Solana Web3.js](https://solana-labs.github.io/solana-web3.js/) & `@solana/wallet-adapter`
- **Styling:** Tailwind CSS
- **Hosting:** [Vercel](https://vercel.com/)
